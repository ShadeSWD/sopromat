# sopromat — Сопротивление материалов: курс и живые расчёты

Статический сайт по курсу сопротивления материалов: теория из шести глав с
выводами формул и схемами плюс расчётно-графические работы, превращённые в
живые расчёты. Никакой сборки и серверной логики: чистые HTML/CSS/JS, весь
расчёт идёт в браузере.

**Прод:** https://shadeswd.duckdns.org/sopromat/ (отдаётся через nginx кластера)

## Содержание
- `site/` — сам сайт (без сборки, чистые HTML/CSS/JS)
  - `index.html` — витрина курса
  - `theory.html` — оглавление курса; страницы глав `t-tension.html` (растяжение
    и сжатие), `t-torsion.html` (кручение), `t-geometry.html` (геометрические
    характеристики), `t-bending.html` (изгиб), `t-deflection.html` (перемещения),
    `t-stability.html` (устойчивость)
  - `rgr1.html` — конструктор составного сечения: 1–8 элементов (лист b×t,
    швеллер ГОСТ 8240, уголок ГОСТ 8509, двутавр ГОСТ 8239, произвольный
    профиль), данные профилей тянутся живой библиотекой справочника кластера
    (`/ref/lib/tables.js`) с вшитой офлайн-копией таблиц; статические моменты,
    центр тяжести, перенос осей по Штейнеру, главные оси и моменты, эллипс
    инерции, схема сечения — всё живое
  - `frame.html` — дважды статически неопределимая рама методом сил: живые
    параметры (l, h, доля стойки-обрубка γ, отношение жёсткостей k, положения
    m, P и участка q), коэффициенты канонических уравнений считаются численным
    перемножением тех же функций эпюр, что рисуются (формула Симпсона, ≥200
    точек на стержень, разбиение по точкам излома), аналитическая сверка
    δ₁₁/δ₁₂/δ₂₂, шесть живых эпюр и деформационная проверка ∫M·M̄ᵢ/EI ≈ 0;
    тумблер «упрощения исходной выкладки» воспроизводит ответ кафедры
    (x₁ = −13,75, x₂ = 32,79)
  - `sources.html` — источники (учебные работы кафедры СПбГМТУ 2022, классические учебники,
    сортаменты ГОСТ)
  - `assets/` — `style.css`, `site.js` (общая навигация)
- `deploy/` — docker-compose (nginx:alpine, 127.0.0.1:8070) + конфиг nginx

## Запуск локально
```bash
cd deploy && docker compose up -d   # проект называется sopromat (name: обязателен!)
```
Сайт поднимется на 127.0.0.1:8070. Наружу отдаётся через nginx хоста
(location /sopromat/). Clean-URL: nginx `try_files $uri $uri.html $uri/` —
ссылки идут без расширения `.html`.

## Тесты
```bash
python3 -m pytest tests/ -q
```
`tests/test_site.py` параметризованно проверяет каждую HTML-страницу (корректный
разбор, отсутствие дублей id, целостность локальных ссылок/ассетов с учётом
clean-URL nginx) и синтаксис каждого JS (`node --check`). Тот же прогон
выполняет GitLab CI (`.gitlab-ci.yml`).
