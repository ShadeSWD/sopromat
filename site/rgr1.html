Составное сечение: центр тяжести и главные моменты

Сечение собрано из трёх профилей: лист, швеллер и равнополочный уголок. Для каждого элемента заданы площадь F, координаты центра тяжести (X, Y) в начальной системе и собственные моменты инерции; дальше всё считается по шагам: статические моменты → центр тяжести → перенос осей → главные оси. По умолчанию — числа исходной работы (швеллер 22А и уголок 11 старого сортамента); кнопкой можно подставить действующие данные ГОСТ из справочника.

ЭлементF, см²X, смY, см I_x соб., см⁴I_y соб., см⁴I_xy соб., см⁴

Центробежный момент уголка вычислен в работе через \(I_{\min}\): $$I_{xy} = -\dfrac{\sqrt{(2I_{\min} - I_x - I_y)^{2} - (I_x - I_y)^{2}}}{2} = -\dfrac{\sqrt{(2\cdot 72{,}7 - 176 - 176)^{2}}}{2} = -206{,}6\ \text{см}^{4}$$ (знак — по ориентации полок). У листа и швеллера оси симметрии → собственный \(I_{xy} = 0\).

Схема сечения

Синие точки — центры тяжести элементов, красная — общий центр тяжести; зелёные оси u, v — главные (повёрнуты на α), пунктирный эллипс — эллипс инерции.

Итоги

Примечание о первоисточнике. В таблице исходной работы плечи ai листа и уголка не согласуются с приведёнными там же координатами Yi: для листа указано a = 1,296, хотя 11,1 − 9,905 = 1,195; для уголка a = −1,864, хотя 8,4 − 9,905 = −1,505. Аналогично по X уголка: плечо b = −6,932 отвечает X = 8,04, а не 8,4 из таблицы. При этом сам центр тяжести (14,972; 9,905) в записке посчитан от табличных координат — то есть плечи и координаты записки взаимно противоречивы, и воспроизвести все её итоги одновременно невозможно в принципе. Наш расчёт ведётся строго от введённых координат и согласован сам с собой (инвариант Ixc+Iyc = Iu+Iv выполняется), поэтому итог отличается от записки (Ixc 542,7 против 574,0; α −3,62° против −6,84°). Кнопка «координаты, согласованные с плечами работы» подставляет Y листа = 11,201, X и Y уголка = 8,04 — это приближает Ixc к записке (574,1); оставшиеся расхождения — следствие описанных противоречий первоисточника.
