Глава 2. Кручение

Кручение — рабочее нагружение всех валов: от гребного вала судна до торсиона подвески. Для круглого сечения задача решается точно и просто, и на ней хорошо видно, как из гипотезы о деформации выводится распределение напряжений.

2.1. Крутящий момент

Внутренний силовой фактор при кручении — крутящий момент T: по методу сечений он равен алгебраической сумме внешних скручивающих моментов по одну сторону от сечения. Вдоль вала с несколькими насаженными колёсами T меняется ступенями — строится эпюра T. Передаваемый валом момент связан с мощностью и частотой вращения: \(T = P/\omega\), где \(\omega = \pi n/30\) при n об/мин.

2.2. Деформация и вывод формулы напряжений

Опыт с сеткой на поверхности вала показывает: поперечные сечения круглого вала остаются плоскими и поворачиваются одно относительно другого как жёсткие диски; радиусы остаются прямыми. Возьмём элемент вала длиной dz, сечения которого повёрнуты друг относительно друга на угол dφ. Волокно на радиусе ρ перекашивается на угол сдвига

$$\gamma = \rho\, \dfrac{d\varphi}{dz} = \rho\, \theta,$$

где \(\theta = d\varphi/dz\) — относительный угол закручивания, одинаковый для всех волокон сечения. По закону Гука при сдвиге \(\tau = G\gamma = G\, \theta\, \rho\): касательные напряжения растут от нуля на оси линейно к поверхности. Осталось связать θ с моментом — сумма моментов элементарных сил \(\tau\, dA\) относительно оси равна T:

$$T = \int_A \tau\, \rho\, dA = G\, \theta \int_A \rho^{2} dA = G\, \theta\, I_p, \qquad I_p = \int_A \rho^{2} dA$$

— полярный момент инерции сечения. Отсюда \(G\theta = T/I_p\), и окончательно

$$\tau = \dfrac{T\, \rho}{I_p},\qquad \tau_{\max} = \dfrac{T\, r}{I_p} = \dfrac{T}{W_p},$$

где \(W_p = I_p/r\) — полярный момент сопротивления.

2.3. Полярные моменты круга и кольца

Для круга диаметром d интегрирование по кольцевым площадкам \(dA = 2\pi\rho\, d\rho\) даёт:

$$I_p = \int_0^{d/2} \rho^{2}\, 2\pi\rho\, d\rho = \dfrac{\pi d^{4}}{32} \approx 0{,}1 d^{4},\qquad W_p = \dfrac{\pi d^{3}}{16} \approx 0{,}2 d^{3}.$$

Для кольца (труба с наружным диаметром D и внутренним d, \(c = d/D\)):

$$I_p = \dfrac{\pi D^{4}}{32}\left(1 - c^{4}\right),\qquad W_p = \dfrac{\pi D^{3}}{16}\left(1 - c^{4}\right).$$

Труба выгодна: материал у оси почти не напряжён (τ там мала), и его перенос к поверхности повышает \(W_p\) при той же массе. Например, при \(c = 0{,}8\) кольцо теряет лишь 41 % момента сопротивления сплошного вала, экономя 64 % площади — поэтому валы больших диаметров и делают полыми.

2.4. Углы закручивания

Из \(G\theta = T/I_p\) угол взаимного поворота концов участка длиной l при постоянном T:

$$\varphi = \dfrac{T\, l}{G\, I_p},$$

а для ступенчатого вала углы складываются по участкам: \(\varphi = \sum T_i l_i/(G_i I_{p i})\). Произведение \(G I_p\) — жёсткость при кручении; для стали \(G \approx 8\cdot 10^{4}\ \text{МПа}\). По эпюре T и жёсткостям строится эпюра углов φ вдоль вала.

2.5. Расчёт вала: прочность и жёсткость

Вал должен удовлетворять двум условиям:

$$\tau_{\max} = \dfrac{T}{W_p} \le [\tau],\qquad \theta = \dfrac{T}{G\, I_p} \le [\theta],$$

где \([\tau] \approx 0{,}5\ldots 0{,}6\, [\sigma]\), а допускаемый относительный угол \([\theta]\) обычно 0,25–1 °/м. Из каждого условия находят свой диаметр и принимают больший: длинные валы чаще «диктуются» жёсткостью, короткие — прочностью. Статически неопределимое кручение (вал, защемлённый обоими концами) решается так же, как в главе 1: к равновесию моментов добавляется условие \(\sum \varphi_i = 0\).
